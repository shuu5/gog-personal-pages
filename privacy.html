gog-personal のプライバシー ポリシー

最終更新: 2026-11-06

gog-personal は、持ち主 1 人が自分の Gmail を扱うためだけの OAuth の client です（概要）。持ち主のほかの人は使いません。

運営者は持ち主個人です。株式会社カエミラの service ではなく、同社の domain を借りて置いています。

1. 読む data

Gmail の API の scope（gmail.modify・gmail.settings.basic・gmail.settings.sharing）で、持ち主の account のメール（header・本文・添付の名）・thread・label・下書き・送信元の設定を読みます。

2. 使い道

持ち主が自分の計算機の上で、自分のメールを探す・読む・整理する（既読と未読・label・アーカイブ・ゴミ箱）・下書きを作るためだけに使います。メールを送る事と、完全に消す事はしません。広告・販売・信用の評価には使いません。

3. 渡す先

持ち主は、自分で使う AI の道具（Anthropic の Claude Code）に、持ち主の指示の範囲でメールの中身を渡して読ませます。この時、中身は Anthropic の service へ送られ、持ち主と Anthropic の契約の条件で扱われます。これ以外の第三者には渡さず、売りません。

4. 保存

Google の login の token は、持ち主の計算機の上で、専用の OS の user だけが読める暗号化した保存先に置きます。メールの中身を別の database に写して貯める事はしません。ただし、Claude Code の会話の記録として、持ち主の計算機に残る事があります。

5. 取り消しと削除

持ち主は、Google の account の「サードパーティ製のアプリとサービス」から、いつでもこの client の許可を取り消せます。取り消すと token は使えなくなり、持ち主は計算機の上の token も消します。

6. Google の規則

Google の API から受け取った情報の使用と転送は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。Google の API から受け取った data を、汎用の AI や機械学習の model の開発・改善・学習に使いません。

7. 問い合わせ

Google の同意の画面に出る support の email へ。

gog-personal Privacy Policy

Last updated: 2026-11-06

gog-personal is an OAuth client used only by its owner, a single individual, to work with the owner's own Gmail account (overview). No one else uses it.

The operator is the owner, an individual. It is not a service of Kaemira Inc.; it only uses a subdomain of that company's domain.

1. Data accessed

Through the Gmail API scopes gmail.modify, gmail.settings.basic and gmail.settings.sharing, it reads the messages (headers, bodies and attachment names), threads, labels, drafts and send-as settings of the owner's account.

2. How the data is used

Only so that the owner, on the owner's own computer, can search, read and organize (read/unread, labels, archive, Trash) the owner's mail and create drafts. It does not send mail or permanently delete mail. The data is not used for advertising, sold, or used for credit assessment.

3. Sharing

The owner passes message content, within the owner's own instructions, to an AI tool the owner uses (Claude Code by Anthropic). That content is sent to Anthropic's service and handled under the terms between the owner and Anthropic. The data is not shared with or sold to any other third party.

4. Storage

The Google sign-in token is stored on the owner's computer in an encrypted store readable only by a dedicated operating-system user. Message content is not copied into a separate database. It may remain on the owner's computer as part of Claude Code conversation logs.

5. Revocation and deletion

The owner can revoke this client's access at any time from "Third-party apps and services" in the Google Account, after which the token no longer works and the owner deletes the token from the computer.

6. Google policy

The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Data received from Google APIs is not used to develop, improve, or train generalized AI or machine-learning models.

7. Contact

Use the support email shown on the Google consent screen.
