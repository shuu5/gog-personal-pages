gog-personal

gog-personal は、持ち主 1 人が自分の Gmail を、自分の計算機の上で動く道具（gogcli）で扱うためだけの OAuth の client です。一般の利用者には提供していません。

この頁は持ち主が個人で運営します。株式会社カエミラの service ではなく、同社の domain を借りて置いています。

する事

  • 持ち主の Gmail のメールを探し、読む
  • 持ち主の指示で、既読と未読・label・アーカイブ・ゴミ箱へ移す事・下書きを作る事をする
  • メールを送る事と、完全に消す事はしない

使う Google の data

Gmail の API の scope（gmail.modify・gmail.settings.basic・gmail.settings.sharing）で、持ち主の account のメール・thread・label・下書き・送信元の設定を読み書きします。扱いは プライバシー ポリシー に書きます。

gog-personal (English)

gog-personal is an OAuth client used only by its owner, a single individual, to work with the owner's own Gmail account through a tool running on the owner's own computer (gogcli). It is not offered to the public.

This page is run by the owner as an individual. It is not a service of Kaemira Inc.; it only uses a subdomain of that company's domain.

What it does

  • Searches and reads the owner's Gmail messages.
  • On the owner's instruction, marks messages read or unread, adds or removes labels, archives, moves messages to Trash, and creates drafts.
  • It does not send mail and does not permanently delete mail.

Google user data it uses

Through the Gmail API scopes gmail.modify, gmail.settings.basic and gmail.settings.sharing, it reads and modifies the messages, threads, labels, drafts and send-as settings of the owner's account. See the Privacy Policy.
